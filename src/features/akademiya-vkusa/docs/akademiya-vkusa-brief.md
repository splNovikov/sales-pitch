## Техническое решение

### Архитектура

#### Frontend
**Платформа:** Next.js  
**Преимущества:**
- Оптимальное SEO
- Высокая производительность
- Современный стек технологий

#### CMS (на выбор)
**Варианты для модерации контента:**
1. **Strapi**
   - Open-source headless CMS
   - Гибкая настройка контент-моделей
   - API-first подход
   - Удобный интерфейс администратора

2. **1С-Битрикс**
   - Комплексное решение
   - Российская разработка
   - Широкая функциональность
   - Техподдержка на русском языке

3. **Sanity.io** *(альтернатива)*
   - Структурированный контент
   - Реал-тайм совместная работа
   - Мощный редактор

4. **Contentful** *(альтернатива)*
   - Enterprise-уровень
   - Масштабируемость
   - Богатый API

### Интеграции

**Статус:** Обязательная интеграция  
**Источник данных:** Информация о блюдах и услугах  
**Учтено в стоимости:** Да
