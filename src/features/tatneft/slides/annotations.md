**SCADA** — Supervisory Control and Data Acquisition (диспетчерское управление и сбор данных).

**SCADA (коротко):** система диспетчерского контроля и сбора данных с объектов (датчики, оборудование).

**SCADA (развёрнуто):** программно-аппаратный комплекс для сбора телеметрии с датчиков и оборудования в реальном времени, визуализации состояния процессов и диспетчерского управления. В нефтедобыче — источник данных с ДНС, скважин, ГЗУ и др. В контексте КП — один из типов систем-источников, из которых данные попадают в Data Lake через ETL.

## 18. Data Lake: схема

**Data Lake (коротко):** единое хранилище телеметрии и инцидентов.

**В нашем случае Data Lake — это:** единое хранилище телеметрии с датчиков оборудования и информации об инцидентах. Данные выгружаются (ETL из источников), очищаются и приводятся к единому формату. Фундамент для подсистемы раннего предупреждения и интерфейса оператора. В скоупе текущего КП — данные по ДНС.

**ETL** — Extract, Transform, Load (извлечение, преобразование, загрузка).

**ETL (коротко):** выгрузка из источников, очистка и загрузка в хранилище.

**ETL (развёрнуто):** процесс выгрузки данных из систем-источников (SCADA, АСУТП и др.), их преобразования — очистка, приведение к единому формату и структуре — и загрузки в единое хранилище (Data Lake). Обеспечивает «один источник правды» для аналитики и подсистемы предупреждений.
