# Проект: редизайн сайта Cameo Hotel

## 1. Контекст и исходные данные

### 1.1. Клиент и объект

- Клиент: **Татьяна**
- Объект: **Cameo Hotel** (отель + апартаменты)
- Домен: **cameo-hotel.ru**
- Текущий сайт: устаревший визуально, неудобный по UX, слабая работа с отзывами и главной страницей
- Система бронирования / CRM: **Travelline** (нет собственной CRM)

### 1.2. Вход контакта

- Формат: холодный звонок → последующий созвон по требованиям → переписка с примерами сайтов и рекомендациями её разработчика
- Статус лида: **хорошо квалифицированный**, заинтересована в работе, но чувствительна к бюджету

### 1.3. Сроки и бюджет

- Желаемый срок завершения работ: **до середины апреля** (4–5 месяцев на реализацию)
- Ориентир по рынку:
  - Предложения от сторонних студий: **150 000 – 200 000 ₽**
  - Есть знакомый-разработчик, предлагающий **существенно более низкий ценник** (у Татьяны вызывает сомнения по качеству)
- Внутренняя «психологическая» планка клиента: **~100 000 ₽**

---

## 2. Цели проекта

1. **Осовременить сайт**, сохранив узнаваемость бренда (цвета, логотип, шрифты)
2. **Сделать удобную мобильную версию** (адаптивный дизайн, mobile-first)
3. **Усилить конверсию в бронирование** через главную страницу и удобную структуру
4. **Интегрировать отзывы** (в том числе из Яндекса) в общем стиле сайта
5. **Сохранить и развить связку с Travelline**, не создавая свою CRM/систему бронирования
6. **Повысить привлекательность сайта визуально** (галереи, возможно видео, современный UI)

---

## 3. Выявленные требования с созвона с Татьяной

### 3.1. Дизайн и брендирование

- Оставить:
  - базовую цветовую палитру,
  - логотип,
  - шрифты (или их аккуратные аналоги, если потребуется для web)
- При этом:
  - полностью осовременить визуал,
  - перерисовать всё в рамках нового дизайн-макета,
  - сделать сайт визуально ближе к современным отельным сайтам-конкурентам.

### 3.2. Мобильная версия

- Обязательное требование — **полноценная адаптивность** для смартфонов и планшетов
- Удобное бронирование и навигация с телефона (основной канал у туристов)

### 3.3. Структура сайта

- Сейчас:
  - лендос играет роль **разводящей страницы** (отель / апартаменты)
- Позиция Татьяны:
  - **не настаивает** на жёстком разделении отеля и апартов,
  - готова к оптимизации структуры, если так станет удобнее пользователю.

### 3.4. Интеграция с отзывами

- Хочет интеграцию с **Яндекс Отзывами**, с выводом отзывов **в стиле сайта**, а не просто стандартный виджет
- Желательно:
  - блоки отзывов на ключевых страницах,
  - визуально аккуратная интеграция (карточки, слайдер, рейтинг и т.п.).

### 3.5. Интеграции и системы

- Собственной CRM нет, всё обработка идет через **Travelline**
- Travelline — основной инструмент для:
  - бронирования,
  - управления номерами и ценами,
  - администрирования загрузки.
- Сайт должен **поддерживать и усиливать** связку с Travelline, а не заменять её.

## 4. Рекомендации от разработчика Татьяны (как внешний инсайт)

> Эти рекомендации не обязательны к буквальному исполнению, но полезны как ориентир по UX/UI и структуре.

### 4.1. Общая оценка текущего сайта

- Дизайн **сильно устарел** — логика: «частичная косметика не спасёт, нужен новый макет»
- UX слабый — мало презентации, мало визуала, слабая роль главной страницы
- Главная страница сейчас — в основном **навигация**, а не «главный продающий экран»
- **SEO-потенциал высок**, видимость можно сильно улучшить с дополнительными работами (поведенческие факторы и т.п.)

### 4.2. Главная страница (как должна работать)

- Сделать главную **самостоятельной и продающей**, не просто навигацией:
  - блок бронирования (без лишних переходов),
  - галереи (общий визуал отеля/апартов),
  - блоки отзывов,
  - основные преимущества и УТП,
  - краткая информация об объектах.

### 4.3. Внутренние страницы

- Внутренние шаблоны строить с приоритетом на **галереи**:
  - интерьер,
  - экстерьер,
  - окружение и достопримечательности.
- Рекомендация подготовить **небольшие профессиональные видео-презентации**:
  - общее видео по объекту,
  - возможно отдельно по отелю и по апартаментам.

### 4.4. Модуль бронирования

- Модуль Travelline — **готовое стороннее решение**
  - их интерфейс бронирования и админка **должны остаться как есть**,
  - можно скорректировать только стили, чтобы визуально он выглядел ближе к сайту.

### 4.5. Отзывы

- Уйти от формата отдельной страницы «Отзывы» — в таком виде они **работают слабо**
- Сделать:
  - распределенные блоки отзывов **на основных страницах**,
  - при возможности — с **выборкой по локациям/объектам** (для конкретного адреса – свои отзывы),
  - собирать отзывы с разных площадок: **Яндекс, другие OTA**, возможна интеграция.
- Отдельно возможно предложить услугу по работе с формированием отзывов на площадках.

### 4.6. Продвижение и SEO

- Видимость сайта в поиске можно существенно улучшить
- Рекомендации:
  - использовать инструменты работы с **поведенческими факторами**,
  - запускать такие работы **до сезона** (важно иметь минимум месяц запаса),
  - в сезон это уже даёт минимальный эффект.

## 6. Предлагаемая концепция нового сайта Cameo Hotel

### 6.1. Общие принципы

- **Сохранить узнаваемость бренда** (цвета, лого, шрифты), при этом полностью обновить UI/UX
- Сайт воспринимается как **единый бренд** с несколькими объектами (отель/апарты/адреса)
- Главная страница — **основной продающий экран**:
  - блок бронирования + выбор объекта,
  - общая презентация,
  - галерея,
  - отзывы,
  - краткая информация об объектах.

### 6.2. Структура страниц (вариант для презентации)

- Главная
  - Хедер: бренд + меню + CTA «Забронировать»
  - Первый экран: фон-фото/видео, форма бронирования (Travelline), выбор объекта
  - Блок «О нас / о Cameo Hotel»
  - Блоки по объектам: Отель / Апартаменты (карточки с адресами)
  - Галерея (общие виды)
  - Блок отзывов (из Яндекса и др. — кастомный стиль)
  - Блок преимуществ (локация, сервис, парковка, завтраки и т.д.)
  - Контакты + карта

- Страница объекта (Отель / Апартаменты)
  - Детальная информация
  - Галереи (интерьер/экстерьер)
  - Блок отзывов по конкретной локации
  - Форма/кнопки бронирования (Travelline)

- Дополнительные разделы (опционально)
  - Акции/спецпредложения
  - О районе / как добраться
  - Вопросы-ответы (FAQ)

### 6.3. Технические моменты

- Адаптивный фронтенд (например, React + Tailwind / либо классический стек)
- Интеграция с **Travelline** (виджет/iframe/форма + стилизация)
- Интеграция с **Яндекс Отзывами** (через API, с кастомной подачей)
- Подготовка к SEO (структура, семантика, скорость)

## 7. Бюджет и сложность (черновой, для аргументации)

> Цифры примерные, для презентации и объяснения клиенту, почему проект ближе к 120–140К, чем к 50–70К.

### Основной функционал

- Дизайн-макет: 15–20К
- Верстка + фронтенд (адаптивный): 30–40К
- Интеграция Travelline (виджет/стили/логику): 10–15К
- Интеграция Яндекс Отзывов + блоки отзывов: 8–12К
- Галереи, медиакомпоненты: 5–8К
- Тестирование, оптимизация, запуск: 10–15К

**Итого базовый диапазон:** ≈ **88–108К**  
(без учета видеопроизводства и активного SEO-продвижения)

### Дополнительно (по желанию клиента)

- Видеосъёмка и монтаж: +20–50К
- Комплексное SEO / работа с поведенческими факторами: +30–50К
- Контент-менеджмент (тексты, наполнение): +10–15К

---

## 8. Ключевые тезисы для презентации

1. **Не косметический ремонт, а полный редизайн**, при сохранении фирменного стиля.
2. **Главная страница становится продающей**, с упором на бронирование и презентацию объекта.
3. **Мобильная версия — приоритет**, под поведение современных гостей.
4. **Отзывы интегрированы в структуру сайта**, а не спрятаны в отдельный раздел.
5. **Travelline остаётся ядром бронирований**, сайт — современная витрина и интерфейс для гостей.
6. Бюджет порядка **100К+** объективно объясняется объемом работ (дизайн, адаптив, интеграции, UX).
7. В перспективе можно усилить сайт за счёт **видео и SEO**, но это уже следующий шаг.
