# ProposalAI — Документация первого уровня (v3)

## Платформа автоматизированного создания презентаций КП

---

## 1. ОБЗОР ПРОДУКТА

### Миссия

Превратить создание качественных презентаций коммерческих предложений из ремесла в no-code процесс. Даже человек без опыта презентологии за 5 минут создаст убедительное КП.

### Целевая аудитория

- **Продажники** (B2B, B2C)
- **Консультанты** (юристы, HR-консалтинг)
- **Бизнес-тренеры**
- **Криптопроекты** (инвесторские питчи)
- Всем, кто нужно быстро сделать презентацию КП/питча

### Базовый принцип

Упростить мотор - вместо промтов (сложно для непрограммиста) → **вопрос-ответ в интерфейсе** (чекбоксы + текстовые поля).

**Ключевая инновация:** Контекст + минимальный контент от пользователя + AI дополнение = профессиональная презентация.

**Главное отличие v3:** Адаптивный wizard — вопросы меняются в зависимости от того, что смогла найти AI. Двухэтапная валидация перед генерацией.

## 2. АРХИТЕКТУРА ВЗАИМОДЕЙСТВИЯ (v3)

### Слой 0: Onboarding (одноразово)

Новый пользователь сначала проходит **Onboarding Wizard** один раз. Здесь собирается контекст компании.

```
Пользователь → Логинится в первый раз → Onboarding Wizard

Вопросы:
  1. О вашей компании
     - Название
     - Сфера деятельности (IT услуги, консалтинг, обучение...)
     - Сайт
     - LinkedIn
     - Краткое описание что вы делаете

  2. Ваши основные сильные стороны (3-5 чекбоксов)
     ☐ Опыт (лет работы)
     ☐ Портфолио кейсов
     ☐ Команда (размер, квалификация)
     ☐ Быстрота выполнения
     ☐ Индивидуальный подход
     ☐ Качество (сертификации, награды)
     ☐ Цена

  3. Основные услуги (динамическое добавление)
     Услуга 1: название + описание (1 абзац)
     Услуга 2: название + описание
     ...

  4. Ключевые показатели компании
     - Кол-во успешных проектов
     - Лет на рынке
     - Размер команды
     - Основной регион / страна

  5. Кейсы (опционально, можно пропустить)
     Добавить 2-3 кейса вручную или оставить пусто (заполнится позже)

Результат: Company Context Profile (сохраняется в базе)
```

### Слой 1: Управление контекстами (Context Management)

После onboarding пользователь может создать **несколько контекстов** (профилей) для разных клиентов/сегментов.

```
[Главный экран] → [Мои контексты]

Пользователь видит список:
  1. [IT услуги для стартапов] (default, из onboarding)
  2. [IT услуги для крупных компаний]
  3. [Аутсорсинг разработки]
  4. [Консалтинг по миграции]

Для каждого контекста:
  - Название контекста
  - Фокус на определённом типе клиента
  - Приоритизированные услуги (какие показываем в первую очередь)
  - Кейсы релевантные для этого сегмента
  - Язык презентации (RU / EN)

Кнопки:
  [+ Создать новый контекст] → Mini Wizard (3-4 вопроса)
  [Редактировать контекст]
  [Удалить контекст]
```

### Слой 2: Адаптивный Wizard (Main Wizard - Multi-page, ADAPTIVE)

**КЛЮЧЕВОЕ ОТЛИЧИЕ V3:** Wizard динамически меняет вопросы в зависимости от того, что смогла найти AI.

#### Общий флоу:

```
Шаг 1: Выбор контекста
  [IT услуги для стартапов]
  [IT услуги для крупные компании]
  [+ Создать новый контекст]

Шаг 2: Выбор типа презентации
  [Тип 1: Research] - анализ клиента
  [Тип 2: Cold Pitch] - универсальный питч
  [Тип 3: Targeted Solution] - целевое решение

Шаг 3: АДАПТИВНЫЕ ВОПРОСЫ (зависит от типа и от результатов парсинга)
  ↓
  Пользователь вводит данные → AI парсит → Wizard адаптируется

Шаг 4: REVIEW STAGE (новое!)
  ↓
  Пользователь ревьюит собранную AI инфу → Редактирует/подтверждает

Шаг 5: ГЕНЕРАЦИЯ
  ↓
  Система генерирует презентацию

Шаг 6: LIVE EDITOR (новое, улучшенное!)
  ↓
  Пользователь редактирует слайды в удобном интерфейсе
```

## 3. АДАПТИВНЫЙ WIZARD (INTELLIGENT ADAPTIVE FLOW)

### Концепция

**Традиционный wizard:**

```
Вопрос 1 → Вопрос 2 → Вопрос 3 → Вопрос 4 → Вопрос 5 → Готово
(всегда одни и те же вопросы)
```

**Адаптивный wizard (v3):**

```
Вопрос 1: "Дайте сайт клиента"
  ↓
  [AI парсит сайт за 3-5 сек]
  ↓
Wizard анализирует собранные данные и решает:

  ✅ Смогли определить сферу деятельности?
     → Пропускаем вопрос про сферу деятельности

  ✅ Смогли найти список услуг/продуктов?
     → Пропускаем вопрос про услуги

  ✅ Смогли найти ключевых людей?
     → Пропускаем вопрос про ключевые люди

  ❌ Не смогли найти контактные данные?
     → Добавляем вопрос "Дайте контакты"

  ❌ Не смогли найти информацию о размере компании?
     → Спрашиваем прямо: "Сколько сотрудников?"

Результат: каждый пользователь получает персонализированный wizard
```

  - Проверка на грамматику
  - Оптимизация для читаемости

РЕЗУЛЬТАТ:
  - Полный контент для презентации
