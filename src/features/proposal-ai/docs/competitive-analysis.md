## 5. РЫНОЧНАЯ НИША ProposalAI

### Кому нужен ProposalAI (и кому не нужен)

```
✅ ИДЕАЛЬНЫЕ ПОЛЬЗОВАТЕЛИ:

1. B2B Sales Professionals
   → Создают КП много раз в месяц
   → Нужно быстро и качественно
   → Есть контекст компании (одинаковый для всех КП)

   ПРИМЕР: Sales manager в IT компании
   Создаёт 5-10 КП в месяц
   Экономит 3-4 часа в неделю

2. IT Consultants
   → Каждому клиенту свой анализ
   → Нужен быстрый research
   → Нужны разные типы питчей

   ПРИМЕР: Freelance consultant
   Перед встречей делает research presentation
   Показывает что понимает клиента

3. Business Coaches / Trainers
   → Нужны универсальные питчи
   → Разные аудитории (стартапы / корпорации)
   → Нужны кейсы

   ПРИМЕР: Coach по продажам
   Создаёт питчи для разных сегментов

4. Entrepreneurs / Fundraisers
   → Нужны инвесторские питчи
   → Много итераций
   → Быстро адаптировать под разные фонды

   ПРИМЕР: Founder готовит питч для VC
   За день 5 вариантов для 5 разных фондов

5. HR Consultants
   → Питчи для клиентов
   → Анализ компании
   → Разные типы презентаций

   ПРИМЕР: HR consultant
   Готовит pitch перед встречей с потенциальным клиентом


❌ НЕ ИДЕАЛЬНЫЕ ПОЛЬЗОВАТЕЛИ:

1. Маркетологи (нужен Canva)
   → Нужен красивый дизайн, а не контент
   → Не нужны КП, нужны социальные посты

2. Дизайнеры (нужен Figma)
   → Хотят контролировать каждый пиксель
   → ProposalAI слишком автоматический

3. Corporate со своим брендом
   → Нужны строгие бренд-гайдлайны
   → ProposalAI ориентирован на скорость

4. Те, кто не создает КП
   → Например, учителя, блогеры
   → Это не их use case
```
