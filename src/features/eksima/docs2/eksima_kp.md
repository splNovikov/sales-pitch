# Коммерческое Предложение

## Платформа для управления заказами розничных точек Eksima

---

# 1. Введение: Текущая ситуация и Возможность

Сегодня розничные точки, работающие с Eksima, сталкиваются с неудобством поиска подходящих товаров, расчета количества и оформления заказов. Текущий инструмент требует улучшения в части **интуитивности интерфейса**, **точности расчетов** и **скорости подбора товара**.

**Наша задача**: создать специализированный инструмент для специалистов по продажам, который:

- Ускорит процесс подбора плитки вместе с клиентом
- Обеспечит прозрачность в ценообразовании (розничные цены для покупателя, управление собственной стоимостью через настройки)
- Позволит Eksima эффективно управлять заказами без засорения системы
- Станет удобным рабочим инструментом, а не просто электронным каталогом

---

# 2. Ключевые Сценарии Использования

## Сценарий 1: Совместный подбор в шоуруме (80% операций)

Специалист по продажам и клиент выбирают плитку прямо на месте:

1. Специалист ищет понравившийся вариант в инструменте
2. Вводит количество (штуки/м²/коробки) — калькулятор пересчитывает автоматически
3. Добавляет в корзину, демонстрирует клиенту **рекомендованные розничные цены** производителя
4. Завершает заказ, который отправляется письмом в Eksima для обработки

**Ключевая особенность**: Клиент видит розничные цены, Eksima управляет собственной стоимостью через настройки приложения.

## Сценарий 2: Самостоятельный подбор через инструмент (20% операций)

Специалист подбирает товар сам через поиск:

- **Визуальный поиск**: "зелененькая в точечку" с AI-ассистентом
- Фильтры по производителю и коллекции
- Быстрый предпросмотр образцов
- Группировка по странам (проверено на практике)

# 3. Основные Компоненты Решения

## 3.1 Каталог с Интеллектуальным Поиском

- **Группировка по странам производителей** (первоначальная фильтрация)
- Поиск по названию коллекции, артикулу, стране
- **Визуальный поиск с AI-ассистентом**: "зелененькая", "под мрамор", "матовая с точками"
- Быстрый предпросмотр без открытия карточки товара
- Фильтры по цвету, текстуре, размеру

## 3.2 Страница Коллекции Бренда

- Обзор всех продуктов производителя
- Информация о бренде
- Фильтры по типу, размеру, поверхности
- Рекомендованные розничные цены производителя
- Связь к каталогу для быстрого перехода

## 3.3 Страница с Плитками Конкретной Коллекции

- Сетка товаров коллекции с превью
- Быстрые фильтры (размер, поверхность, цвет)
- Сортировка (популярность, цена, новинки)
- Информация о наличии и сроках поставки
- Прямой доступ к карточке товара и добавлению в корзину

## 3.4 Карточка Товара с Калькулятором

- Конвертация: штуки ↔ м² ↔ коробки в реальном времени
- Итоговая стоимость на основе рекомендованных розничных цен
- Информация о наличии и сроках поставки
- Галерея изображений товара
- Характеристики (размер, поверхность, тон, калибр)

## 3.5 Корзина Специалиста

- Сохранение заказов для каждого юридического лица
- Возможность сохранить черновик для возврата позже
- Контроль суммы и состава заказа
- Редактирование количества каждой позиции
- Удаление товаров из корзины

## 3.6 История Заказов

- Статусы заказов: "Принят", "Собирают", "Готов", "Доставляется", "Выполнен", "Отменен"
- Фильтры по дате, статусу, менеджеру, предприятию
- Быстрый доступ к повторному заказу (копирование позиций)
- Детальная информация по каждому заказу с датой и суммой

## 3.7 Оформление Заказа

- Выбор предприятия (юридического лица)
- Выбор ответственного менеджера
- Подтверждение наличия товара и сроков
- Отправка письмом в Eksima (без резервирования в 1С для исключения засорения)
- Уведомление об отправке и номер заказа

## 3.8 Настройки Администратора

- **Управление розничными ценами**: переключение между рекомендованными производителем ценами
- **Управление собственной стоимостью**: коэффициент наценки или фиксированная маржа для каждого предприятия
- Управление пользователями и правами доступа
- Настройки синхронизации с 1С
- Управление предприятиями и их менеджерами

## 3.9 Система Уведомлений

- Email-уведомления о смене статуса заказа
- Напоминания о незавершенных заказах (опциональные)
- Оповещения администратору о новых заказах
- История всех уведомлений в личном кабинете

# 5. Технический Стек и Архитектура

## Выбранный Вариант: React Frontend + Bitrix Backend

### Frontend (Lovable.dev → React)

- **Фреймворк**: React с TypeScript
- **UI-компоненты**: готовые компоненты Lovable + кастомизация
- **Состояние**: Context API / Redux
- **HTTP-клиент**: Axios для работы с Bitrix API
- **AI-интеграция**: встраивание модели для визуального поиска
- **Быстрота разработки**: ~4-6 недель

### Backend (Bitrix24)

- **Существующая инфраструктура**: используем текущую систему Eksima
- **REST API** для коммуникации с фронтендом
- **Синхронизация с 1С**: регулярная выгрузка товаров и цен
- **Управление пользователями**: интеграция с Bitrix
- **Email-рассылка**: встроенный функционал Bitrix
- **Логирование заказов**: база в Bitrix для истории

### Синхронизация данных (1С → Bitrix → Frontend)

```
1С Eksima
    ↓ (полная выгрузка каждую ночь + дельта каждые 2 часа)
Bitrix REST API (каталог + цены + наличие)
    ↓
React Frontend (отображение товаров, поиск)
    ↓
Корзина и заказы
    ↓
Email письмо в Eksima (на адрес заказов)
```

**Периодичность обновления**:

- Полная выгрузка: ночь (00:00 MSK)
- Дельта-обновление цен и наличия: каждые 2 часа
