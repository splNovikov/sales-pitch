# 1. ПОИСК С ГРУППИРОВКОЙ ДЛЯ ПРОДАВЦОВ

## Проблема текущей версии

Текущий поиск ориентирован на классический e-commerce. Для продавцов, работающих в шоуруме, нужен совсем другой подход.

## Рекомендуемая архитектура поиска

### Уровень 1: Первичная группировка по странам (80% фильтрации)

**Ключевой момент**: На каждом этапе должно быть максимум 8-12 кликабельных элементов. Это ускоряет навигацию.

Структура навигации:
1. **Каталог (первый вход)** → блоки по странам (Россия, Испания, Италия, Китай)
2. **Внутри страны** → бренды и коллекции (max 8-12 позиций)
3. **Внутри бренда** → список коллекций
4. **Внутри коллекции** → сетка с превью плиток

### Уровень 2: AI-ассистент для визуального поиска

**Триггер**: кнопка "🔍 Помощь в поиске" или "Что вам нужно?" на каждом уровне

**Сценарии использования**:
- Пользователь: "Зелёненькая в точечку"
- AI анализирует: зелёный цвет + текстура с точками → фильтрует по цветовому пространству + наличие орнаментов
- **Результат**: Показывает топ-5 подходящих коллекций из Испании/Италии

**Реализация**:
1. Frontend: текстовое поле + микрофон (voice-to-text)
2. Backend: интеграция с API визуального поиска (Claude Vision API или аналог)
3. База данных плиток: теги цвета, фактуры, стиля для каждой плитки

**Mockup процесса**:
```
Пользователь → "Мне нужна тёмно-серая с мраморным эффектом"
                    ↓
            AI-анализ (Claude Vision или аналог)
                    ↓
            SQL запрос: WHERE color LIKE 'gray_dark' AND pattern LIKE 'marble'
                    ↓
            Результаты: Durstone Silestone + DNA Marmol + Equipe Metropolis
                    ↓
            Показать топ-3 коллекции с preview
```

### Улучшения поиска на странице результатов

**Фильтры**:
- По размеру (30×30, 60×60, 120×60, мозаика)
- По поверхности (матовая, глянцевая, структурированная)
- По цветовому диапазону (слайдер или палитра)
- По типу (напольная, настенная, универсальная)

**Сортировка**:
- По популярности (использование в заказах)
- По наличию (в наличии ↔ под заказ)
- По цене (возрастание/убывание)

**История поисков**: 
- Сохранять последние 5-7 поисков специалиста
- "Вы ищете: зелёненькая" + quick-add кнопка
