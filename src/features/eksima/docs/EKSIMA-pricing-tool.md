е# EKSIMA: Инструмент предоставления цен

---

## Слайд 1: Название и описание

### Инструмент предоставления цен

**by EKSIMA**

Персональная система ценообразования для розничных партнеров с возможностью управления наценками и прямого шаринга каталогов с покупателями.

---

## Слайд 2: Проблема и решение

### Задача

Как дать розничным партнёрам (юр. лицам) инструмент для:

- Управления собственными наценками
- Демонстрации цен конечным покупателям
- Быстрого шаринга каталога без лишних усложнений

### Решение

Единая система авторизации с двухуровневым ценообразованием:

1. **Вход в систему** → партнёр получает свои персональные цены от EKSIMA
2. **Управление наценками** → партнёр регулирует свою маржу
3. **Шаринг каталога** → прямая ссылка для покупателей

---

## Слайд 3: Система авторизации

### Вход в систему

```
EKSIMA → Формирует персональные цены для каждого юр. лица
         ↓
         Юр. лицо авторизуется в системе
         ↓
         Получает доступ к каталогу с цено-ценами и собственной идентикой
```

**Модель партнёрства:**

- Каждому партнёру установлена собственная оптовая цена (может отличаться от других)
- Партнёр видит эту цену только в режиме работы ("МОИ ЦЕНЫ")
- Партнёр платит EKSIMA по установленной цене, продаёт покупателю по своей цене

---

## Слайд 4: Каталог после входа

### Вид после авторизации

Партнёр видит каталог товаров с:

- **Собственной идентикой** (логотип, цветовая схема)
- **Базовыми ценами** (это его оптовые цены от EKSIMA)
- **Возможностью управления** наценками на каждый товар

### Пример: Керамогранит Coliseum Brenta Grey 22,5х90

```
Товар: Керамогранит Coliseum Brenta Grey 22,5х90
Артикул: CB-22590-BRENTA-GR
Описание: Керамогранит, размер 22,5х90 см, серый цвет

На этом экране партнёр видит базовую информацию и может начать управление ценообразованием
```

## Слайд 6: Неограниченные розничные точки

### Множество собственных каталогов

Юр. лицо НЕ ограничено количеством создания своих розничных точек с собственным ценообразованием:

```
EKSIMA (Поставщик)
    ↓
    Юр. лицо "ООО СТРОЙСНАБ" (Партнёр)
    ├─ Розничная точка №1 (Москва)
    │  └─ Наценка на керамогранит: 1.80x
    │
    ├─ Розничная точка №2 (СПб)
    │  └─ Наценка на керамогранит: 2.00x
    │
    └─ Розничная точка №3 (Казань)
       └─ Наценка на керамогранит: 1.70x
```

Каждая точка может иметь:

- Собственную наценку на один и тот же товар
- Собственную идентику (логотип, название)
- Собственный каталог для шаринга

## Слайд 8: Объяснение персонального токена в URL (простым языком)

### Что такое эта "непонятная ссылка"?

Нормальная ссылка выглядит так:

```
https://eksima.ru/catalog
```

Но если поделиться ей просто — никто не узнает, чей это каталог.

Поэтому система добавляет "личный билет" (токен):

```
https://eksima.ru/catalog?view=customer&partner=partner_123&token=abc7k9F2mL
```

**Это означает:**

- `view=customer` — "показать режим для покупателя" (без себестоимости)
- `partner=partner_123` — "это каталог партнёра с ID partner_123"
- `token=abc7k9F2mL` — "это персональный ключ доступа" (уникален для каждого шара)

**Аналогия:** Как если вы даёте другу вашу записную книжку — никто другой не будет знать, что это ваши контакты.

### Преимущества такого подхода:

- ✅ Покупатель видит ЕГО цены (партнёра), не EKSIMA цены
- ✅ Невозможно "подглядеть" цены других партнёров
- ✅ Каждый токен уникален — можно отследить кто открыл
- ✅ Токен можно отозвать в любой момент

## Слайд 9: Клиентский режим (без авторизации)

### Покупатель открывает ссылку

Покупатель получил ссылку от партнёра и открывает её:

```
https://eksima.ru/catalog?view=customer&partner=partner_123&token=abc7k9F2mL
```

**Что происходит:**

1. Покупатель НЕ авторизуется (не нужен логин/пароль)
2. Система проверяет токен — валидный ли он?
3. Если валидный → показывает каталог этого партнёра
4. Если невалидный (истёк, отозван) → ошибка "доступ недоступен"

### Что видит покупатель на экране:

```
┌─────────────────────────────────────────┐
│  Логотип компании "ООО СТРОЙСНАБ"       │  ← Идентика партнера
├─────────────────────────────────────────┤
│                                         │
│  Керамогранит Coliseum Brenta Grey      │
│  22,5х90                                │
│  ────────────────────────────────────   │
│  Цена: 1 044 ₽                          │
│  [Добавить в корзину]                   │
│                                         │
│  [Далее в каталоге 200+ товаров]       │
│                                         │
└─────────────────────────────────────────┘
```

**Что НЕ видит:**

- ❌ Себестоимость (580 ₽)
- ❌ Коэффициент наценки (1.80x)
- ❌ Маржу партнёра (464 ₽)
- ❌ Никаких кнопок управления или админ-панели

**Это полностью "чистый" каталог** — как обычный интернет-магазин.

## Слайд 10: Архитектура решения

### Как всё работает под капотом

```
┌─────────────────────────────────────────────────────────┐
│                    EKSIMA Backend                        │
│                                                          │
│  ├─ Хранит базовые товары                              │
│  ├─ Устанавливает оптовую цену для каждого партнера   │
│  ├─ Выдаёт токены доступа при шаринге                 │
│  └─ Валидирует токены при открытии ссылок             │
└─────────────────────────────────────────────────────────┘
                           ↓
        ┌──────────────────┴──────────────────┐
        ↓                                      ↓
┌──────────────────────┐          ┌──────────────────────┐
│  Партнёр работает    │          │ Покупатель открывает │
│  (авторизован)       │          │ ссылку               │
│                      │          │ (БЕЗ авторизации)    │
│ - Видит оптовые цены │          │                      │
│ - Управляет наценки  │          │ - Видит розничные    │
│ - Шарит каталог      │          │   цены партнера      │
│                      │          │ - Добавляет в        │
│                      │          │   корзину            │
└──────────────────────┘          └──────────────────────┘
```

### Два разных способа показа одного товара

**Для партнера:**

```javascript
{
  name: "Керамогранит Coliseum Brenta Grey 22,5х90",
  supplierPrice: 580,      // Оптовая цена от EKSIMA
  markupCoeff: 1.80,       // Наценка партнера
  retailPrice: 1044,       // 580 × 1.80
  margin: 464              // 1044 - 580
}
```

**Для покупателя (по ссылке):**

```javascript
{
  name: "Керамогранит Coliseum Brenta Grey 22,5х90",
  retailPrice: 1044        // ТОЛЬКО это
  // Всё остальное скрыто!
}
```

## Слайд 12: Резюме

### EKSIMA Pricing Tool

Это инструмент, который позволяет:

1. **Партнёрам** → управлять своими ценами и демонстрировать их покупателям
2. **Покупателям** → видеть актуальные цены без лишних сложностей
3. **EKSIMA** → масштабировать продажи без увеличения нагрузки на поддержку

### Как это работает в одной фразе

_«Партнёр авторизуется → видит свои оптовые цены → устанавливает наценку → шарит ссылку с покупателем → покупатель видит готовый каталог с ценами партнера»_
