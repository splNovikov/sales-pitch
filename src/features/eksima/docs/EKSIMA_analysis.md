## Портрет компании

**EKSIMA** – это керамическая студия и оптовый поставщик керамической плитки и керамогранита, функционирующая на российском рынке строительных материалов с 2006 года. Компания позиционирует себя как **представитель крупнейших российских производителей керамического гранита и плитки**, предоставляя как оптовые, так и розничные услуги.

Компания обслуживает как B2B сегмент (оптовые покупатели, строительные компании, дизайнеры), так и B2C сегмент (розничные покупатели). Основной фокус – оптовые продажи, что является стратегической нишей для расширения и автоматизации через инструментарий для онлайн-покупок.

## Потребности компании

### 1. **Критическая потребность: Инструментарий для оптовых покупателей (B2B кабинет)**

**Контекст:** Заказчик явно выразил потребность в **инструментарии** (не называя его кабинетом) для оптовых покупателей. Это является основной целью сотрудничества.

**Функциональность, которая требуется:**

#### Минимальный набор функций:

- [ ] **Каталог товаров** – структурированный список с параметрами:
  - Артикул и наименование
  - Остатки на складе
  - Оптовые цены (с брейками по объемам)
  - Фото продукции
  - Сертификаты и документация

- [ ] **Личный кабинет покупателя**:
  - Регистрация и авторизация
  - История заказов
  - Сохраненные товары и корзина
  - Персональные скидки и специальные предложения
  - Реквизиты компании-покупателя

- [ ] **Оформление заказа**:
  - Добавление товаров в корзину
  - Изменение количества
  - Расчет стоимости с учетом скидок
  - Выбор способа доставки
  - Сохранение черновиков

- [ ] **Управление заказами**:
  - Просмотр статуса заказа
  - История платежей
  - Печать документов (счет-фактура, накладная)
  - Уведомления о статусе

#### Расширенный набор функций:

- [ ] **Аналитика для оптовиков**:
  - Сравнение цен по объемам закупок
  - Рекомендации по совместимым товарам
  - Прогноз затрат

- [ ] **Управление поставками**:
  - Отслеживание доставки в реальном времени
  - Планирование заказов
  - Автоматические уведомления при поступлении новой продукции

- [ ] **Интеграции**:
  - 1С:Бухгалтерия
  - Payment gateway (Яндекс.Касса, Юкасса, Сбербанк)
  - Email уведомления
  - SMS оповещение

- [ ] **Управление доступом**:
  - Групповые учетные записи (несколько пользователей от одной компании)
  - Разграничение прав доступа
  - Установка лимитов закупок

### 2. **Бизнес-потребности**

#### a) Увеличение объема оптовых продаж

- Снижение трудозатрат на обработку заказов
- Автоматизация коммуникаций
- Повышение удобства для оптовиков (доступ 24/7)
- Возможность расширения географии продаж

#### b) Улучшение управления складом

- Автоматизированное управление остатками
- Синхронизация с ERP/1C системой
- Предотвращение пересортировки
- Оптимизация логистики

#### c) Оптимизация коммуникаций

- Сокращение времени на обработку запросов
- Автоматизированные уведомления
- Снижение количества ошибок при передаче данных

#### d) Расширение рынка в условиях санкций

- Переориентация на отечественного клиента
- Удобный интерфейс для привлечения новых оптовиков
- Конкурентное преимущество перед игроками без онлайн-платформы

### 3. **Технические потребности**

- Надежная хостинг-инфраструктура
- Быстрая загрузка каталога (>1000 артикулов)
- Безопасность данных
- Масштабируемость при росте количества пользователей
- Мобильная версия или PWA для удобства
